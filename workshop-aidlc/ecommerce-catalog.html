E-Commerce Product Catalog

Build a local-first full-stack product catalog using AI-DLC methodology

This workshop demonstrates incremental unit-by-unit development. Build, test, and validate each unit before moving forward.

Workshop Overview

Stack: React / Vite / FastAPI / SQLite / Docker Compose

Apply AI-DLC methodology to build a local-first e-commerce product catalog. Customers can browse products, search, view details, and add items to a SQLite-backed cart. Admins can manage products and inventory without login. Product images use static placeholder image URLs.

Prerequisites

  • Basic programming knowledge
  • Access to AI assistant (Kiro, Claude, Cursor, etc.)
  • Node.js LTS and npm
  • Python 3.11+, venv, and pip
  • Browser for local frontend and API docs validation
  • Docker Compose (optional, for the Operations packaging step — a no-Docker path is provided)
  • Code editor

Inception Activity 3: User Stories Creation
What's a user story? A user story is a short, plain-language description of something a user wants to do, written from their point of view, usually in the form: "As a customer, I want to add a product to my cart so that I can buy it later." Each story also lists acceptance criteria (the specific conditions that must be true for it to count as done). Together, these stories become the contract for everything the AI builds next, so it's worth getting them right.

Construction Activity 5: Domain Model Creation
What are SQLite and seed data? SQLite is a small database kept in a single file on your own machine, so products, inventory, and cart contents survive a restart without running a separate database server. Seed data is sample content shipped with the app — here, a starter set of products — so the catalog isn't empty the first time you open it. The model below decides what tables hold this data and how the app reads and writes them.
