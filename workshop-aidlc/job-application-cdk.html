Local Job Application Website

Build a frontend-only job application site using React, Vite, seeded data, and localStorage

Follow the complete AI-DLC methodology to build a local-first job application site with open-source frontend tooling.

Workshop Overview

Project: Job Application Site | Stack: React / Vite / localStorage

Build a frontend-only job application management site that allows applicants to search, view, and apply to seeded job postings. Submitted applications are stored in browser localStorage. Docker Compose packaging is reserved for the Operations step.

Prerequisites

  • Basic React/JavaScript knowledge
  • Access to an AI assistant (Kiro, Claude, Cursor, etc.)
  • Node.js LTS and npm installed
  • Browser for local preview and localStorage testing
  • Docker Compose (optional, for the Operations packaging step — a no-Docker path is provided)
  • Code editor
Workshop 2 Setup Instructions

Task Overview

We have just been hired by a new client to build their hit new job board. They are not very technical and are vague about the details. Here is what they have told us so far:

“We want a site where people looking for work can browse the jobs we have posted and apply right from the page. Folks should be able to search and narrow things down so they aren't scrolling forever, and it would be nice if they could save the postings they like to come back to later. That's roughly what we're picturing for now.”

Inception Step 1: Intent to User Stories
What's a user story? A user story is a short, plain-language description of something a user wants to do, written from their point of view, usually in the form: "As a user, I want to apply to a job so that I can be considered for it." Each story also lists acceptance criteria (the specific conditions that must be true for it to count as done). Together, these stories become the contract for everything the AI builds next, so it's worth getting them right.

What are seeded data and localStorage? Seeded data is sample content you ship with the app so it isn't empty on first run — here, a set of made-up job postings to browse. localStorage is a small storage area built into your browser that keeps data on your own machine, so an application you submit is still there after you refresh or reopen the page, with no server or database involved.

Operations Step 5: Local Static Packaging
What does packaging a static build mean? Vite turns your React app into plain HTML, CSS, and JavaScript files in a dist folder — that's the "production build." Serving it just means handing those files to a browser, which a tiny web server (Nginx, or a local preview server) does. Packaging with Docker bundles that server and the files together so the site starts the same way on any machine. Pick the version that matches your setup below — both produce the same deployment guide and validation report.
